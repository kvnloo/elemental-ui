# Elemental UI — AI material image assets

This directory contains the exact generated PNG files from the Oct 12 2026 conversation (basalt x6, slate x3, showcase x5), plus curated reusable prompt templates.

Important: an ImageGen PBR illustration or a dark shaded macro is **not** a physical scanner output. It is an artistic reference/texture source and may include baked shadows, impossible normals, undefined physical scale, nonperiodic edges, and made-up height. The actual Blender material dream loop must validate physically meaningful maps generated from a common height/geometry source and a consistent color workflow. Native resolutions and SHA-256 checksums are in assets.manifest.json; no image was upscaled.

The original STONE inspirational UI images were credited @jimiplouffe; these files are newly generated visual targets, not copies of those source images. Detailed prompt templates are reconstructions because original generation prompt metadata was empty.

For future scale, move heavyweight generated previews to an artifact store or Git LFS rather than growing Git history without bounds.
